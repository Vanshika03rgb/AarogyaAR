# AarogyaAR
AR-powered medication assistance platform for elderly patients using Unity, Vuforia and Firebase.
# AarogyaAR

See Right. Take Right. Stay Safe.

## Problem

Elderly patients often struggle to identify the correct medicine due to:

- Similar-looking medicine strips
- Tiny labels
- Multiple prescriptions
- Medication confusion

## Solution

AarogyaAR uses Augmented Reality to:

- Recognize medicines
- Provide voice guidance
- Highlight required medicines
- Reduce medication errors
- Improve medication safety

## Tech Stack

- Unity
- Vuforia Engine
- Firebase
- Android
- Speech Recognition
- Gemini API (Planned)
